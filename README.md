## 🚀 Overview
The **Customer Feedback Sentiment Analyzer** is an enterprise-grade Natural Language Processing (NLP) web application designed to analyze academic and course feedback with high granularity. Powered by robust machine learning classifiers, sentiment scoring engines, and **Explainable AI (XAI)**, this platform bridges raw textual feedback with actionable institutional insights.

---

## ✨ Key Features & Architecture
1. **🔍 Live Review Inference & Explainability:**
   * Instant sentiment classification (Positive, Neutral, Negative) with confidence probability scores.
   * Granular Aspect-Based Sentiment Analysis (ABSA) breaking down feedback across core curriculum and delivery pillars.
   * Explainable AI (SHAP) feature impact visualization highlighting influential keywords driving model predictions.
2. **📈 Confusion Matrix & Decision Dashboard:**
   * Comprehensive evaluation metrics including Precision, Recall, Macro F1-Score, and Accuracy.
   * Executive decision insights identifying model strengths and boundary misclassifications for strategic academic intervention.
3. **🎯 Aspect-Based Intelligence Hub:**
   * Dedicated evaluations for Content Quality, Instructor Delivery, Pacing & Speed, and Hands-on Labs.
4. **📁 Batch CSV Dataset Processor:**
   * Bulk inference support allowing institutions to upload raw review datasets, process predictions at scale, and export clean CSV reports.
